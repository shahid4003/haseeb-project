# CampusConnect

A campus event management web app with Admin, Attendee, Volunteer and Vendor roles. Built with plain HTML, CSS and JavaScript. No build step needed.

## Run it

```bash
git clone git@github.com:shahid4003/haseeb-project.git
cd haseeb-project
python3 -m http.server 8000
```

Open <http://localhost:8000>, type your name, pick a role and sign in. You can also just open `index.html` in your browser.
